SECTION 1 — PROJECT OVERVIEW
--------------------------------------------------------------------

emu‑os is a small console‑style operating system built on Buildroot.  
It boots fast, uses SDL2 for the UI, mpv for background video, RetroArch for emulation, and supports USB boot with ROMs stored on an exFAT partition.

Features:
- SDL2 menu
- SDL2 first‑boot wizard
- mpv background video
- RetroArch integration
- Controller auto‑mapping
- USB boot with ROMDATA partition
- Auto‑mount exFAT ROM partition
- Buildroot‑based kernel + rootfs
- Fully automated rebuild script

Folder layout:
buildroot/          Buildroot configs + board files  
package/emu_menu/   SDL2 menu package  
package/emu_setup/  First‑boot wizard package  
emu-menu-src/       SDL2 menu source  
emu-setup-src/      SDL2 wizard source  
overlay/            Rootfs overlay  
roms/               ROM folders (for testing)  
share/emu/          Background videos  
install_emu_os_usb.sh  USB installer script  
rebuild_emu_os.sh   Full project generator

SECTION 11 — HOW TO BUILD EMU-OS
--------------------------------------------------------------------

You must use Linux.  
Options:
- WSL2 on Windows  
- VMware Linux VM  
- Native Linux machine  

Steps:

1. Install dependencies  
sudo apt install build-essential bc bison flex libssl-dev libncurses5-dev cpio rsync

2. Place your emu-os folder inside Buildroot

3. Run:  
make emu_x86_64_defconfig

4. Build:  
make -j$(nproc)

5. Use USB installer:  
sudo ./install_emu_os_usb.sh /dev/sdX bzImage rootfs.cpio.gz

6. Add ROMs to ROMDATA partition

7. Boot from USB
